# Longform (FanFiction Reader)

- DB lives at `~/Library/Application Support/com.lhak1341.longform/longform.db` — safe to inspect/edit directly with `sqlite3` while `bun run tauri dev` is running. The release app from `bun run deploy` shares this same DB (same bundle id), so test runs touch the real library.
- `docs/SPEC.md` is the living spec — read the relevant section before touching scraping/fetch/data-model code, and update it when behavior changes.
- No `docs/adr/` — architectural decisions live in `docs/wayfinder/map.md` + tickets (macro) and inline `// architecture review candidate N` comments (micro; rejections too, written "Architecture review candidate N (date), rejected:") — `grep -i` that phrase uncapped (no `head`) before proposing a refactor, and before rating a candidate read the code it cites *and whatever consumes the field/key it calls mismatched*, and grep `docs/SPEC.md` for the behavior it calls a gap (it may be recorded policy) (past reviews overstated about half their candidates).
- `temp/` (repo root, gitignored) is this project's scratch/output dir, not OS tmp.
- Background `bun run tauri dev`/vite processes are invisible to `ps aux` — use `lsof -i :1420` / `lsof +D src-tauri/target` instead. This shell has no `timeout` — use `run_in_background` + manual sleep/check.
- This app can't be screenshot-verified (Tauri's WKWebView isn't CDP-attachable, no `window.__TAURI__` outside the real shell) — for UI changes, ask the user to check the running app directly. For a feature that adds or moves rows, also `sqlite3` the live DB and check where the default sort/filters would place them: a story can be imported yet invisible (ranked last, hidden by a filter, wrong screen). Before rejecting or validating a stored value, count the live rows that would violate the new rule (decides whether a repair is needed).
- Backend (Rust/Tauri) conventions: see `src-tauri/CLAUDE.md`. Frontend (Svelte) conventions: see `src/CLAUDE.md`. Test-writing conventions: see `docs/TESTING.md`. Live-fetch verification: see `docs/FETCH_TESTING.md`.

## Standard commands (same names in all my Tauri apps)

`bun run tauri:dev` native app with hot reload · `bun run tauri:build` release bundle · `bun run deploy` build, quit the running copy, install into `~/Applications`, then `sweep-targets` (needs `cargo install cargo-sweep`) · `bun run check` type-check · `bun run test` · `bun run lint` (warning ceiling in `.lint-baseline.json`; `lint:full` shows findings, `lint:baseline` locks a lower count) · `bun run format` / `format:check`. Dev ports: translator 5174, fanfiction-reader 1420, family-ledger 1430. Husky `pre-commit` runs lint-staged and ratchets the lint baseline down; CI runs check, lint, format:check, test and `cargo test`. `scripts/install-app.sh` is identical in all three — it reads the app name from `tauri.conf.json`.
