# src-tauri (Rust/Tauri backend)

- `cargo check`/`cargo test` through the `rtk` hook can print a misleadingly terse summary (e.g. "cargo build (0 crates compiled)") that hides real errors/warnings — use `rtk proxy cargo <args>` when verifying changes. `Cargo.toml` lives here, not repo root — `cd src-tauri` first. The same hook can mangle plain `ls`/`grep` output on files under `target/` into truncated garbage — fall back to a Python file read if output looks wrong.
- Rust↔TS and Rust↔permission drift fails `cargo test` through text-scan guards, so a miss breaks the build instead of failing at runtime. A new `#[tauri::command]` needs `invoke_handler!` (`lib.rs`) AND `commands.allow` in a `permissions/*.toml` (one per window/capability, see `capabilities/*.json`; `tests/command_registration.rs`). The keys `src/lib/api.ts` sends must equal the command's non-injected parameter names, camelCased, both ways (`tests/command_args.rs`): only `api.ts` is scanned, not the debug page's raw `invoke`; an `Option<T>` param must still be sent as `paramName: null`; a type that crosses IPC as a param needs `#[derive(serde::Deserialize)]` (a type that only ever stays in-process, like `FfnListingLocator`, must not be a param); an `invoke(` shape the guard can't read panics instead of being skipped. Every `Serialize` type in `src/*.rs` must be listed in `MIRRORED_STRUCTS` (with a same-named `types.ts` interface, camelCase fields) or `UNMIRRORED_TYPES` with the reason it never crosses (`tests/type_mirror.rs`; `Deserialize`-only types such as `StoryFilters` are excluded, see its doc comment). A new `stories` column goes in both `UPSERT_*_STORY_SQL` consts in `db.rs` unless truly per-source (`upsert_sql_columns_cover_the_schema`). A new fetch command returns a `*Fetched` struct from `dispatch.rs` and needs its `types.ts` interface.
- Changing an existing Tauri command's signature: some commands are also called as plain Rust fns from other commands, not just from `src/lib/api.ts`/`invoke()` (e.g. `search_ffn` calls `search_ffn_via(...).await` directly) — check both kinds of caller.
- Before trusting a schema migration in `migrations.rs`, copy the real DB to scratch and check `PRAGMA integrity_check`/`PRAGMA foreign_key_check`/row counts against the copy — don't just trust the SQL in isolation. Stays manual; no instance of this class has happened yet — record the first one here.
- rusqlite's `row.get("col_name")` needs an explicit `AS col_name` on every SQL expression (COALESCE, subqueries included) — bare `table.column` refs get a default name, but expressions don't. A `StoryRow` query gets a test that runs it (in-memory `db::tests::memory_conn()` plus the seeded `list_stories` suite), which catches a missing `AS` at `cargo test` time.
- When merging near-identical branches during a dedup refactor, check each one for an invariant-enforcing `unreachable!()`/`assert` before collapsing them — it reads like duplication but silently dropping it removes a real safety check.
- `tokio` has only the `rt`+`sync`+`time` features: no `#[tokio::test]`/`join!`/`start_paused` — async tests build a `current_thread` runtime by hand, use `tokio::spawn` for a fake page report and short real timeouts (see `fetch_session.rs` tests and `fetch_env::testing::FakeEnv`). A test that opens a real socket (`fetch_env.rs`'s `reqwest_get` loopback tests) needs `.enable_all()` on that runtime — `enable_time()` alone panics with "IO is disabled".
- Every fetch command is a thin Tauri adapter over a `*_via(env, db, session, …)` function in `fetch.rs` taking a `&impl FetchEnv` (`fetch_env.rs`: `navigate`, `get`, `save_debug_page`). A new fetch command gets the same pair, and its test builds a `FakeEnv` (scripted FFN reports via `FakeEnv::new`, scripted AO3 responses via `FakeEnv::ao3`) — never `AppHandle`.
- `cargo fmt --check` and `cargo clippy --all-targets` already fail on untouched code (no rustfmt config; wide hand-formatted lines, a `type_complexity` warning at `ffn.rs:155`) — only `cargo test` gates a change; never run `cargo fmt` (rewrites whole files). Diff the warning list before/after instead.
